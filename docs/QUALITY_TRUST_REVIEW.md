本轮基于 `bccf994`，只修改新 `upstream_v2` 写作适配层及离线测试。未修改上游、模型配置、公共 CLI、持久化 schema、旧后端、历史任务或测试集。没有调用真实模型、运行训练、重跑测试集或生成新论文。以下论文诊断来自旧后端案例，不能作为新后端已有同样缺陷的证明。

## 1. 历史论文诊断

样本：`case-studies/pathtest-001/papers/final_paper_en.pdf` 与 `final_paper_zh-CN.pdf`。提取两份全文，并渲染核对相关正文页面；历史 PDF 保持原样。

| 位置与原文实例 | 判断 | 本轮应对 |
|---|---|---|

| 英文 p3 Discussion：`According to the contract results`，随后重复阈值与 guardrail | 讨论偏向流程验收，尚未充分解释结果 | 现有 reviewer 检查讨论是否重复结果、是否混入内部术语 |
| 英文 p1 Related Work 按架构、正则化、提示学习等罗列研究 | 与本次标签平滑假设之间的依据关系不够清晰；不等于这些文献无效 | 单列已有摘要和相关性依据；缺少依据时不编造 research gap |

## 2. 实际修改与上游复用

`pathmnist/upstream_publication.py` 中增加确定性的研究说明组织函数。其内容依次为研究问题、文献依据、预设条件、对照设计、观察结果、结论限制；全部取自已有证据。缺失字段明确写为未提供，引用键与原参考文献顺序一致。

写作器的 idea 位置现在接收研究说明，不再接收包含完整分析、版本和图表哈希的身份 JSON。完整实验证据仍作为原生 experiment summaries 提供，包括配置、种子、选择规则和不同 split 的结果；不以删减科学事实换取简洁。完整分析和版本仍参与输入指纹，不降低缓存隔离。

仍直接调用上游 `writeup_step`、`perform_review`、`reflection_step`。仅在既有调用中增加研究论证与风格要求，没有新模型调用、Agent 或审稿器。现有最多两次 reflection 和编译退出条件保留；因此不能说所有科学审阅问题都已关闭。翻译机制不变。

恢复时新增一个验收顺序修复：在复制模板、图表或恢复缓存投影之前，逐一校验已有 publication manifest 的已提交阶段产物。否则，曾经有效但后来被修改的论文可能被缓存重新写回，从而掩盖改动。现在拒绝继续并保留改动现场；缺失的未提交响应投影仍可从有效缓存回执恢复。无需新 schema。

## 3. 可信链路覆盖与边界

| 环节：输入 → 输出 | 现有验收与本轮测试 | 边界 |
|---|---|---|
| 数据与样本 → 预测及指标 | `scientific_integrity` 检查样本 ID、标签、集合完整性并重算指标；新增遗漏样本且不写回执测试，已有重复和错标签测试继续通过 | 重算只能证明预测对应的指标，不能单独证明预测来自声明的模型 |
| 研究合同 → 实验配置 | 已有合同批准哈希、配置和重复要求测试 | 声明检查不能证明任意 Python 训练实现完全遵循声明 |
| 保存实验 → 后续复用 | `verified_metrics` 验证代码、数据、seed、validation split 和重算指标；新增 test 产物不能冒充 validation 测试 | 无法防御同时伪造所有信任记录的行为 |
| 实验快照 → 恢复 | `snapshot_evidence` 已有哈希绑定；新增配置、role 记录、结果修改测试，并验证再次快照不能覆盖被改内容 | 本轮检验冻结后角色记录被改；不宣称检测所有语义上的实验组互换 |
| 冻结候选 → 一次测试 | 已有代码变化拒绝执行、完成测试恢复及结果篡改测试 | 没有真实训练或测试集调用 |
| 图表 → 首次论文输入 | 现有验收检查文件、PNG 头与来源清单 | **首次交接缺少持久化图表内容绑定**；用户已确认本轮记录，另行规划 |
| 首次写作 → 后续恢复 | 图表内容参与写作指纹；新增源图被替换则要求版本审查测试 | 不补证首次写作之前的图表真实性 |
| 已提交论文／审阅 → 恢复 | 新增四个阶段文件篡改拦截测试，既有中断恢复、预算失败和不重复调用测试继续运行 | 不自动修复被改文件，不等于语义证明每句话受证据支持 |

另行规划的事项：首次图表交接哈希绑定及兼容规则；更强的实验组／指标语义绑定；可信推理执行证明；与实验进程分离的不可改记录。没有擅自扩大到这些结构性变更。
